HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Sign in or create a free account at https://github.com/
2. Click the + icon, choose New repository.
3. Name it: sai-finance-reality
4. Select Public, then Create repository.
5. Choose Add file > Upload files.
6. Upload index.html, style.css and script.js (you can also upload this README).
7. Click Commit changes.
8. Open Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Select branch main and folder /(root), then Save.
11. Wait a few minutes. Your free website address will appear on the Pages screen.
